## 1. Project Overview  
This RESTful API provides functionality to manage **employees** and **branches** in an organization.  
This is the backend for **Assignment 5 – BED**, enhanced to include:  

- Full **OpenAPI (Swagger)** documentation  
- Inline **Joi** schema documentation  
- Secure configuration using **dotenv** and `.env`  
- API security using **Helmet.js**  
- Controlled **CORS** policy  
- Automated deployment of API docs to **GitHub Pages**

**Core Features:**

- Create, read, update, and delete branches  
- Create and manage employees, including filtering by department or branch  
- Public API documentation for easy integration by frontend or other developers
